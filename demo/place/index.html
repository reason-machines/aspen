It is a real repository. Each tile is a file holding one color.

    Tile file rules
    • Path tiles/<x>_<y>.txt, with x and y from 0.
    • Contents: exactly #rrggbb in lowercase plus one newline, 8 bytes, using a palette color.
    • Regular files only. No other paths, no deletions, no merge commits.
    • Push to any branch except main; the merger bot folds it in. Up to 64 tiles per push.
